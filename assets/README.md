# assets/

Place all game media here using lowercase-hyphen naming:

- `background.webp`         – Lagos street background (≤150 KB)
- `slingshot.png`           – Y-frame, transparent PNG (240×320 @2x)
- `rock.png`                – Rock sprite, transparent PNG (96×96 @2x)
- `bottle-green.png`        – Single unbranded green bottle (120×320 @2x)
- `shatter-sheet.png`       – 6-frame sprite sheet (960×320 @2x)
- `sfx-glass-1.ogg`         – Glass shatter variant 1
- `sfx-glass-2.ogg`         – Glass shatter variant 2
- `sfx-glass-3.ogg`         – Glass shatter variant 3
- `sfx-shoot.ogg`           – Release twang
- `sfx-whoosh.ogg`          – Rock whoosh
- `sfx-miss.ogg`            – Miss thud
- `sfx-combo.ogg`           – Combo chime
- `sfx-round-end.ogg`       – Round end fanfare
- `sfx-tap.ogg`             – UI tap
- `music-loop.ogg`          – Afrobeats loop (60-90 s, ≤900 KB)
- `logo.svg`                – Brand logo (single colour SVG)
- `wall-banner.webp`        – Brand wall banner (600×200)
- `icon-512.png`            – Store icon (512×512 PNG, NOT SVG)

## MVP status
The MVP ships without these files – all visuals are drawn in canvas code
and all audio is synthesised with the Web Audio API.
Swap in real files one at a time without changing game logic.
